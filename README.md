# CrowPanelWeather

Weather forecast display for the Elecrow CrowPanel ESP32-S3 4.2-inch 400×300 e-paper HMI.

- [Hardware specifications](specs)
- [Requirements](requirements.md)
- [User stories](user-stories.md)
- [Weather icons and graphical assets](assets/README.md)

Selected UI: Classic three / Classic five with a persistent view toggle, black header, matched-height current temperature and weather symbol, and a dotted 5°C graph grid. Planned data source: Open-Meteo, with hourly automatic updates and manual refresh.

The repository currently contains specifications, design requirements and generated assets. Device firmware is not implemented yet.
